Məxfilik siyasəti

Son yenilənmə: 3 oktyabr 2026

Bu siyasət yalnız @magicstory.az hesabının Instagram mesaj köməkçisini təsvir edir. Kitabların hazırlanması, çapı və çatdırılması üçün ayrıca məlumat emalı bu sənədin əhatəsinə daxil deyil.

1. Biz kimik və necə əlaqə saxlamaq olar?

Xidmət Magic Story tərəfindən @magicstory.az Instagram hesabı üçün idarə olunur.

Məxfilik, məlumatların düzəldilməsi və silinməsi ilə bağlı müraciətləri həmin hesaba mesajla və ya camallaoyrenin@gmail.com ünvanına göndərə bilərsiniz.

2. Hansı məlumatlar işlənir?

Instagram-ın tətbiqə təqdim etdiyi məlumatlar çərçivəsində aşağıdakılar işlənə bilər:

  • Instagram istifadəçi adı, hesab/söhbət identifikatorları;
  • mesajların mətni, vaxtı, istiqaməti və mesaj identifikatorları;
  • göndərilən əlavələrin API-nin təqdim etdiyi məlumatları, o cümlədən mövcud olduqda media keçidləri;
  • müştərinin könüllü yazdığı ad, telefon, seçilən məhsul, uşağın adı və yaşı;
  • söhbətin qısa xülasəsi, ilkin sifariş müraciəti və geri dönüş xatırlatmaları.

Bot Instagram şifrənizi, bank kartı məlumatlarını və şəxsiyyət sənədlərini istəmir. Belə məlumatları mesajla göndərməyin. Şəkil və videoların məzmunu hazırkı bot tərəfindən avtomatik təhlil olunmur; onların yoxlanılması satıcıya yönləndirilir.

3. Məlumatlar hansı məqsədlə istifadə olunur?

Məqsəd suallara cavab hazırlamaq, əvvəlki söhbəti nəzərə almaq, müştərinin artıq verdiyi məlumatları təkrar soruşmamaq, ilkin sifariş müraciətini qeyd etmək və satıcının manual cavabını aşkar etməkdir.

Köməkçi süni intellektdən istifadə edə bilər. Ödənişin təsdiqi, sifarişin istehsala verilməsi, geri ödəniş və digər yekun satış qərarları satıcı tərəfindən qəbul olunur. İstənilən vaxt insanla danışmaq istədiyinizi bildirə bilərsiniz.

4. Məlumatlar harada saxlanılır və kimlərə ötürülür?

Botun söhbət yaddaşı və ilkin sifariş qeydləri Magic Story operatorunun kompüterində saxlanılır. Yerli backup və operatorun yaratdığı ixrac faylları da məlumatları ehtiva edə bilər. Lokal idarəetmə paneli internetə açılmır.

Xidmətin işləməsi üçün aşağıdakı provayderlər iştirak edir:

  • Meta/Instagram: mesajların çatdırılması, hesab icazələri və mesaj tarixçəsinə API çıxışı;
  • OpenAI/Codex: cavab və xülasə hazırlamaq üçün son mesajların mətnindən seçilmiş hissələr, saxlanmış söhbət xülasəsi və zəruri ilkin sifariş məlumatları ötürülür. Buraya müştərinin mətnlə verdiyi ad, uşağın adı/yaşı və əlaqə məlumatları daxil ola bilər. Bu, tam offline emal deyil;
  • ngrok: Meta-dan gələn bildirişlərin internet üzərindən operatorun kompüterinə çatdırılması.
  • GitHub Pages (siyasət səhifəsinin yerləşdirilməsi): bu açıq məxfilik və silinmə təlimatı səhifələrini göstərir. Botun kodu, tokenləri və müştəri söhbətləri bu sayta yüklənmir. GitHub səhifə ziyarətçilərinin IP ünvanlarını təhlükəsizlik məqsədilə qeydə ala bilər. Bu statik səhifələrdə sifariş və mesaj daxil etmək üçün forma yoxdur.

Provayderlərin məlumat emalı və saxlama qaydaları onların öz siyasətlərindən və istifadə olunan hesabın ayarlarından asılıdır. Bu sənəd həmin provayderlərdə sıfır saxlama və ya model təlimindən avtomatik istisna zəmanəti vermir. Hazırkı bot şəkil/video fayllarını Codex-ə görüntü təhlili üçün göndərmir.

5. Saxlama və silinmə

Söhbət yaddaşı və ilkin sifariş məlumatları operator tərəfindən silinənədək lokal yaddaşda saxlanılır. Avtomatik vaxtlı silinmə yoxdur; tətbiqin dayandırılması və ya kompüterin söndürülməsi bu məlumatları silmir.

Məlumatların düzəldilməsi, avtomatik cavabın dayandırılması və ya silinməsi üçün yuxarıdakı əlaqə kanallarına müraciət edə bilərsiniz. Müraciət uyğun hesabı müəyyənləşdirmək üçün yoxlanılır və operator tərəfindən işlənir. Lokal məlumatların silinməsində backup və ixrac nüsxələri də ayrıca nəzərə alınmalıdır.

Magic Story-nin lokal yaddaşdan silməsi Instagram-dakı mesajları və provayderlərin saxladığı nüsxələri avtomatik silmir. Həmin məlumatlar üçün müvafiq platformanın ayarları və müraciət kanalları tətbiq olunur.

6. Uşaqlar haqqında məlumatlar

Xidmət valideyn və qanuni nümayəndələrin məhsulla bağlı müraciətləri üçün nəzərdə tutulur. Uşağın məlumatlarını yalnız paylaşmağa səlahiyyəti olan valideyn və ya qanuni nümayəndə təqdim etməlidir. Məhsul üçün zəruri olmayan həssas məlumatları göndərməyin.

Bu köməkçi məlumatları emal üçün qəbul edə bildiyinə görə məlumat göndərməzdən əvvəl bu siyasəti nəzərdən keçirin. Uşağın məlumatlarının istifadəsinə etiraz və ya silinmə tələbi ilə bizə müraciət edə bilərsiniz.

7. Təhlükəsizlik və məhdudiyyətlər

Hesab bağlantısı üçün tokenlər operatorun kompüterində məhdud fayl icazələri ilə saxlanılır. Lokal məlumat və backup-lar hazırkı tətbiq tərəfindən ayrıca şifrələnmir; onların qorunması kompüterin təhlükəsizlik ayarlarından və operatorun nəzarətindən də asılıdır. İnternet ötürülmələrində HTTPS istifadə olunur. Heç bir sistem üçün tam təhlükəsizlik zəmanəti verilmir.

Instagram API bütün keçmiş və silinmiş mesajları həmişə təqdim etmir. Botun yaddaşı yalnız əlçatan API məlumatları və qəbul etdiyi bildirişlər əsasında qurulur. Süni intellekt cavabında səhv və ya qeyri-dəqiqlik ola bilər; vacib məlumatı satıcı ilə dəqiqləşdirin.

8. Dəyişikliklər

Məlumat axını, istifadə olunan provayderlər və saxlama qaydaları dəyişdikdə siyasət də yenilənməlidir. Yayımlanmış versiyada son yenilənmə tarixi göstəriləcək.
